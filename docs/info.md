## How it works

Like how a bullet hell game works, the character (blue) is controllable with the arrow keys and can start the game at first with the down key. The moving red blocks on the screen will damage the player and take one life. the player is immune to damage for a few seconds for fairness. If all lives are lost, the character can no longer be controlled. The screen turns red as indication of a game over, and the time is frozen to show the score. Pressing the down key restarts the game.

## How to test

Using the game controller keys (up down left right) for control. Press the down key to start the game. The player on screen (blue) must avoid the moving red blocks on screen, or the player loses one life (green dots). After all the three dots are lost, the game is over. The player can restart by pressing the down key again.
